## Overview

The paper *"Taming the Curse of Dimensionality: Quantitative Economics with Deep Learning"* is purely computational: it uses no external data, and all numerical results are produced by simulation in the authors' own code.

This replication package contains two Python files:

- `stochastic_growth_pytorch.py` solves a stochastic neoclassical growth model end-to-end, providing both a Newton-based baseline solver and a deep-learning solver.
- `generate_paper_figures_pytorch.py` is the top-level entry point: it calls `stochastic_growth(...)` with the paper's default parameters and writes every figure and in-text number reported in the paper to the `.figures/` directory.

End-to-end runtime is under 10 minutes on a current laptop. No GPU is required.

## Description of programs/code

- `stochastic_growth_pytorch.py` — end-to-end module that solves the stochastic neoclassical growth model. Supports two baseline algorithms via `base_solver_set.solver`:
  - `"newton"` (default): Newton's method in float64 using `torch.func.jacrev` for the Jacobian and `torch.linalg.solve` for the Newton step, globalized with backtracking line search. Achieves machine-precision Euler residuals (~1e-15 mean) in roughly 5 iterations.
  - `"lbfgs"`: L-BFGS minimizes the sum of squared Euler residuals. Because it is an optimizer rather than a root-finder, it can stall at saddle points where the gradient vanishes but residuals remain nonzero, limiting accuracy to ~1e-5 regardless of iteration count or dtype.

  The same module also implements the deep-learning solver described in the paper.
- `generate_paper_figures_pytorch.py` — top-level entry point. Calls `stochastic_growth(...)` with the paper's default parameters (declared at lines 50–103 of that file) and saves all paper outputs to `.figures/`.
- `pyproject.toml`, `uv.lock`, `requirements.txt` — dependency manifests (`uv.lock` is the authoritative pin; `requirements.txt` is a `pip`-compatible export).
- `.python-version` — pins Python to 3.13 for tools that read this file.

## Instructions to Replicators

The Data Editor receives the replication package as a zip file. To replicate from that zip:

1. Install `uv` (one-line install per *Software Requirements* above) if not already present.
2. Unzip the replication package and navigate to its root directory in a terminal.
3. Run the top-level reproduction script:
   ```bash
   uv run python generate_paper_figures_pytorch.py
   ```
   This will first synchronize the locked Python environment (`uv` creates `.venv/` and installs every dependency from `uv.lock`), then run the script. No separate `uv sync` step is required.
4. Inspect the outputs in `./.figures/`. The directory will contain the figure PDFs (`solution_k_trajectories.pdf`, `solution_err_trajectories.pdf`) and one `results.json` summarizing every in-text numerical value. An additional diagnostic file, `solution_log_err_trajectories.pdf` (a log-scale view of the relative policy error), is also written but is not used as a paper figure.

For users replicating from the public source repository instead of the zip, the entire workflow reduces to four shell commands:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
git clone https://github.com/HighDimensionalEconLab/taming.git
cd taming
uv run python generate_paper_figures_pytorch.py
```
